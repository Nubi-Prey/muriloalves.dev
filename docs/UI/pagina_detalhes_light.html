DESAFIO

A Complexidade Óptica

DIOPTER_MATRIX_FAIL

Laboratórios de montagem óptica e grandes redes varejistas mantêm gaveteiros físicos contendo mais de 2.500 variações de lentes por material. Cada bloco é indexado simultaneamente por dois eixos: Grau Esférico (-10.00 a +8.00 em passos de 0.25) e Grau Cilíndrico (0.00 a -4.00).

close Falhas de Soluções Baseadas em Nuvem:
  • Latência de requisição HTTP (150ms-600ms) trava o ritmo do operador de expedição.
  • Quedas na rede local paralisam a conferência na bancada de corte biselador.
  • Interfaces genéricas de e-commerce não suportam a visualização em grade 2D contínua.
SOLUÇÃO

Abordagem Local-First

PERSISTENCE_ZERO_LATENCY

O EstoqueLentes roda inteiramente embarcado no hardware do operador. Utiliza um processo Node.js comunicando via IPC binário com uma base SQLite local armazenada no diretório app.getPath('userData'), gerando tempos de resposta de mutação inferiores a 2 milissegundos.

check Ganhos Operacionais Aferidos:
  • Independência total de internet: 100% dos dados residem no disco local criptografado.
  • Renderização reativa da matriz dióptrica completa sem quedas de frames (60 FPS estável).
  • Auto-save atômico imediato a cada bipe do leitor de código de barras USB.

Decisões de Arquitetura

[04 MÓDULOS ESSENCIAIS]
MOD_01 save

1. Persistência Local-First com Zero Latência

Uso direto de SQLite incorporado através do driver síncrono de alto desempenho better-sqlite3, eliminando a sobrecarga de conexões TCP e custos de instâncias na nuvem. Migrações automáticas de schema são executadas deterministicamente no boot do app antes de abrir a janela principal.

→ Arquivo íntegro mantido em disco local com WAL (Write-Ahead Logging)
MOD_02 grid_4x4

2. Matriz Dióptrica 2D de Alta Performance

Construção de uma grade de dados bidimensional especializada para oftálmica (Esférico no eixo Y vertical vs. Cilíndrico no eixo X horizontal). Mapeamento de células com código cromático de densidade de estoque (crítico, regular, excedente) e navegação completa por atalhos de teclado (WASD / Setas + Enter).

→ Consulta e incremento atômico de saldos com visualização instantânea
MOD_03 verified_user

3. Isolamento Estrito de Segurança IPC

Mitigação das vulnerabilidades clássicas do Electron mantendo o processo de visualização (React) sem permissões de acesso ao sistema de arquivos (nodeIntegration: false). Comunicação realizada exclusivamente através de contratos declarativos TypeScript com validação bidirecional.

→ Superfície de ataque reduzida com total isolamento de contexto
MOD_04 sensors

4. Hardware I/O & Leitor de Código de Barras

Tratamento de eventos em nível de sistema de leitores USB operando no modo Keyboard Wedge HID. Implementação de algoritmo de detecção de cadência ultrarrápida (< 20ms entre caracteres) com debounce adaptativo para diferenciar a digitação manual de operador do bipe de código de barras.

→ Entrada e baixa de estoque contínua em segundos sem perda de foco

// Definição do Schema Drizzle com índices compostos para busca bidimensional imediata
import { sqliteTable, text, integer, real, index } from 'drizzle-orm/sqlite-core';

export const lenses = sqliteTable('lenses', {
  id: text('id').primaryKey(),
  spherical: real('spherical').notNull(),          // Ex: -2.50, +1.75
  cylindrical: real('cylindrical').notNull(),      // Ex: -0.75, 0.00
  axis: integer('axis'),                          // Opcional quando bloco semi-acabado
  material: text('material').notNull(),          // CR-39, Policarbonato, Alto Índice
  quantity: integer('quantity').notNull().default(0),
  barcode: text('barcode').unique(),
  drawerSlot: text('drawer_slot'),               // Localização física da gaveta
  updatedAt: integer('updated_at', { mode: 'timestamp' })
}, (table) => ({
  diopterIdx: index('diopter_idx').on(table.spherical, table.cylindrical, table.material)
}));
// IPC Handler de Mutação Atômica no Processo Main
ipcMain.handle('lenses:adjustQuantity', async (_, { lensId, delta }) => {
  return db.transaction((tx) => {
    const current = tx.select().from(lenses).where(eq(lenses.id, lensId)).get();
    if (!current) throw new Error('LENS_NOT_FOUND');

    const newQty = Math.max(0, current.quantity + delta);
    tx.update(lenses)
      .set({ quantity: newQty, updatedAt: new Date() })
      .where(eq(lenses.id, lensId))
      .run();

    return { success: true, newQuantity: newQty };
  });
});
